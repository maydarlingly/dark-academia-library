# The Invisible Library — Полуночная библиотека

Интерактивная 3D-библиотека в стиле Dark Academia: тёмное дерево, свечи, камин, лунный свет из окна и старинные шкафы, разбитые по жанрам.

**Стек:** Vite · Three.js · GSAP · Tailwind CSS v4 · JSON + `localStorage` · деплой на Vercel.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production-сборка в dist/
npm run preview   # проверить сборку локально
```

Нужен Node.js 20.19+ (или 22.12+).

## Формат данных

`public/data/catalog.json` — список жанров (каждый жанр = шкаф) и книг:

```json
{
  "id": "dracula",
  "title": "Дракула",
  "author": "Брэм Стокер",
  "year": 1897,
  "genre": "gothic",
  "description": "…",
  "spine": { "color": "#4a1414", "height": 0.25, "thickness": 0.055 }
}
```

`spine` задаёт внешний вид корешка: цвет кожи, высоту и толщину в метрах.
Каждый жанр встаёт на свою полку шкафа (порядок — `GENRE_ROWS` в `src/scene/Library.js`),
свободное место заполняют декоративные тома без надписей.

`public/data/books/<id>.json` — текст книги (грузится только при открытии):

```json
{
  "id": "dracula",
  "title": "Дракула",
  "author": "Брэм Стокер",
  "language": "ru",
  "translator": "…",
  "excerpt": true,
  "source": { "name": "Викитека", "url": "https://ru.wikisource.org/wiki/…", "license": "PD-old-70" },
  "chapters": [
    { "title": "Глава I", "verse": false, "paragraphs": ["…", "…"] }
  ]
}
```

- `verse: true` — стихи: каждый элемент `paragraphs` — строфа, строки разделены `\n`.
- `excerpt: true` — в файле только начало книги; в конце читалка покажет «Конец отрывка» и ссылку на источник.
- `source` и `translator` выводятся на титульном листе.

## Навигация по залу

1. **Зал.** Нажмите на шкаф — камера подойдёт к той полке, по которой вы попали.
   (Мышью можно сразу щёлкнуть и по самой книге.)
2. **У полки.** Книги крупно, книги каталога слегка светятся. Внизу панель:
   - кнопки с названиями книг этой полки — самый простой способ открыть книгу на телефоне;
   - ▲▼, колёсико мыши, стрелки ↑↓ или вертикальный свайп — соседняя полка;
   - ◀▶, стрелки ←→ или перетаскивание — вдоль полки (если ряд не помещается на экране);
   - «В зал» или Esc — назад к общему виду.
   На телефоне тап рядом с корешком выбирает ближайшую книгу.
3. **Книга.** Камера подлетает, открывается карточка. «Вернуть» — снова к той же полке.

## Читалка

- Текст верстается под текущий экран: на широком — разворот из двух страниц, на телефоне — одна.
  Каждая глава с новой страницы, буквица, переносы, колонтитулы и номера страниц.
- Книга подлетает закрытой, обложка распахивается вокруг корешка; при выходе — закрывается.
- Листание: щелчок по странице (левая — назад, правая — вперёд; на телефоне левая треть — назад),
  кнопки ‹ ›, стрелки ← →, PageUp/PageDown, свайп. Esc закрывает книгу.
- Лист не поворачивается доской, а изгибается, как бумага: он нарезан на вертикальные полосы,
  каждая повёрнута относительно соседней — внешний край идёт первым и первым же ложится.
  Изгиб затеняется по углу к свету, на соседние страницы падает мягкая тень.
- Звуки синтезируются Web Audio — файлов нет: хруст волокон при отрыве листа, свист воздуха
  (с панорамой по направлению листания), шлепок при приземлении; скрип переплёта; тихое
  шуршание кожи по дереву, когда книга выдвигается из ряда и задвигается обратно.
  Кнопка с динамиком (в шапке и в читалке) выключает звук; выбор запоминается.
- Закладка пишется в `localStorage` при каждом листании: номер страницы и точное место в тексте
  (глава, абзац, слово) — поэтому на другом экране книга откроется на том же месте.
- Выделите текст мышью или пальцем → «Сохранить цитату» → цитата появится в «Моих полках».

## Мои полки

- **Полка** — книги, отложенные кнопкой «На полку». «×» на корешке или «Снять с полки» в списке убирают книгу.
- **Списки** — «Читаю», «В планах», «Прочитано», «Отложено», «Заброшено». Список выбирается в карточке
  книги или прямо здесь; фильтр сверху показывает один список. Открыли книгу в читалке впервые —
  она сама попадает в «Читаю» (если ещё не была ни в одном списке).
- **Цитаты** — сохранённые из читалки, с кнопкой «Удалить».
- Любое удаление можно отменить кнопкой «Вернуть» внизу панели.

Живая деревянная полка со свечой: книги, отложенные кнопкой «На полку», встают на неё корешками
(цвет и размер — из `spine` в каталоге). Новая книга вылетает из карточки к кнопке «Мои полки»,
а при открытии панели падает на полку с отскоком; снятая уходит, соседи плавно сдвигаются (GSAP Flip).
Щелчок по корешку — камера летит к этой книге в зале.

## Деплой на Vercel

1. Запушьте репозиторий на GitHub.
2. На [vercel.com/new](https://vercel.com/new) нажмите **Import** у этого репозитория.
3. Vercel сам определит Vite (`npm run build` → `dist`). Нажмите **Deploy**.

После этого каждый `git push` в `main` автоматически пересобирает сайт.
